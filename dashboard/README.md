# Dashboard

Unified web dashboard for monitoring all trading bots.

## Features (Planned)

- Real-time bot status
- Position and P&L tracking
- Trade history
- Configuration UI

## Usage

```bash
# Build
cargo build --release -p dashboard

# Run (default port 8080)
./target/release/dashboard

# Custom port
DASHBOARD_PORT=3000 ./target/release/dashboard
```
